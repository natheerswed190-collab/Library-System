# 📚 نظام إدارة المكتبة التفاعلي (Library System)

مشروع تفاعلي متكامل لتطبيق مفاهيم البرمجة كائنية التوجه (OOP) ومقرر البرمجة 3 باستخدام لغة Java.

## 🏛️ مفاهيم الـ OOP المطبقة في المشروع:
* الأصناف المجردة (Abstract Classes): تم تمثيلها في صنف الأب المجرد Book.
* الوراثة (Inheritance): يرث صنف PhysicalBook وصنف EBook الخصائص الأساسية من الأب.
* تعدد الأشكال (Polymorphism): تم استغلاله لتخزين أنواع الكتب المختلفة داخل مصفوفة موحدة.
* الأغلفة وحماية البيانات (Encapsulation): استخدام المتغيرات الخاصة private وحمايتها بدوال الجلب والتعديل (Getters & Setters).

## 📦 ميزات النظام التفاعلي:
1. إضافة كتاب جديد: تخيير المستخدم بين كتاب ورقي أو إلكتروني وحساب مكافأة مالية مناسبة للزبون تلقائياً في الخلفية.
2. البحث والشراء: البحث عن الكتب بالاسم (مع تجاهل حالة الأحرف) والتحقق من رصيد الزبون قبل إتمام عملية الشراء وخصم المبلغ من رصيد المستخدم، مع دعم خاصية الرجوع للقائمة الرئيسية.
3. عرض كافة الكتب: استعراض محتويات المكتبة وتفاصيل كل كتاب باستخدام القوائم الديناميكية المرنة (ArrayList).
4. تفقد رصيد المستخدم الحالي: ميزة مدمجة ترتبط بكائن الـ Customer لعرض الحساب المالي المحدث.
